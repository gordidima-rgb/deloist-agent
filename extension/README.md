# Расширение Deloist для Chrome и Edge

Боты Deloist работают в настоящем браузере человека: в своих вкладках (группа
«Deloist · имя бота»), через `chrome.debugger`, по каналу Native Messaging к программе.
Бот работает через Native Messaging только в своих вкладках.

Программа держит копию этих файлов внутри себя (`src/user_chrome.rs`, `include_str!`) и
пишет их в папку данных, в `chrome-extension/`. Человек загружает именно ту папку — так
расширение всегда той же версии, что и программа.

## Постоянный id

`manifest.json` содержит `key` — открытый ключ dev-сборки. С ним распакованное
расширение получает один и тот же id на любом компьютере:
`aicphofdeimagdepgjfkookblhldmcja`. Этот id записан в `native_host::EXTENSION_IDS`:
из него строятся `allowed_origins` манифеста хоста и проверка в самом хосте.

Как пересчитать id из ключа: SHA-256 от байтов ключа (base64 → DER), первые 16 байт в
hex, цифры `0–f` заменить буквами `a–p`.

## Chrome Web Store

Публикация — решение владельца. Когда она будет:

1. Убрать `key` из `manifest.json` (магазин подписывает своим ключом и не принимает поле).
2. Добавить id из магазина в `native_host::EXTENSION_IDS` (dev-id оставить для разработки).
3. Собрать архив из этой папки без `README.md`.

## Связь (pairing)

При первом подключении расширение показывает «Не связано». Программа показывает в окне
6-словный код связи; человек вводит его в окно расширения. Из кода расширение получает
32-байтный ключ (SHA-256 от кода) и хранит в `chrome.storage.local`. Каждый кадр между
расширением и программой несёт `mac = HMAC-SHA256(key, nonce || body)` со счётчиком-nonce;
кадры с неверным MAC или повторным nonce отбрасываются обеими сторонами. Программа хранит
свой экземпляр ключа в DPAPI-хранилище секретов, а не в `runtime.json`.

Связь защищает от подмены программы или хоста: без ключа чужая программа не пройдёт проверку.
Атакующее ПО того же пользователя с кейлоггером вне области защиты (оно может перехватить код
при вводе).

## Сборка нет

Обычный JavaScript без сборщика и зависимостей: что лежит здесь, то и загружается.
Идея (Native Messaging + `chrome.debugger` на вкладки) — как у OpenBot Recorder
(MIT); их код сюда не копировался.
