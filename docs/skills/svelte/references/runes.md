# Руны (Svelte 5.57, доки 2026-11-11)

Руны — ключевые слова компилятора с префиксом `$`. Не импортируются, не значения (нельзя присвоить переменной или передать функции), допустимы только в определённых позициях. Работают в `.svelte` и `.svelte.js`/`.svelte.ts`.

## $state

```js
let count = $state(0);
let todos = $state([{ done: false, text: 'a' }]);   // глубокий прокси
todos[0].done = true;  todos.push({ done: false, text: 'b' });  // оба реактивны
```
- Прокси строится рекурсивно, пока не встретится не-простой объект (класс, `Object.create`).
- Не деструктурировать прокси (`let { done } = todos[0]` ломает реактивность).
- Поля класса: `class Todo { done = $state(false); }`. Методы-стрелки, если метод передают как колбэк.
- `$state.raw(obj)` — мелкое: мутации не отслеживаются, обновлять переприсваиванием целиком. Для больших данных только на чтение.
- `$state.snapshot(x)` — обычная копия (для внешних API, `structuredClone`, логов).
- Передача в функции: значение копируется; нужна живая связь — передавать геттеры `() => a`.

## $derived

```js
const doubled = $derived(count * 2);
const total = $derived.by(() => { let s = 0; for (const n of numbers) s += n; return s; });
```
Только чистые выражения, без побочных эффектов. Значение можно временно переприсвоить (оптимистичный UI), оно вернётся при следующем изменении зависимостей.

## $effect

```js
$effect(() => {
  const id = setInterval(tick, 1000);
  return () => clearInterval(id);       // уборка обязательна
});
```
- Запускается после обновления DOM и после монтирования; зависимости собираются автоматически (только то, что прочитано синхронно).
- Не использовать для вычисления состояния из состояния — это `$derived`.
- `$effect.pre` — до обновления DOM (автопрокрутка). `$effect.tracking()` — внутри ли реактивного контекста. `$effect.root(fn)` — ручной корень, уборку вызывать самому. `$effect.pending()` — идут ли async-ожидания.
- **Стоимость:** каждый таймер/подписка в эффекте живёт, пока компонент жив. Эффекты без нужды — минус CPU.

## $props, $bindable, $props.id

```js
let { adjective = 'happy', super: trouper, ...rest } = $props();
const uid = $props.id();                       // уникальный id экземпляра для label/for
let { value = $bindable() } = $props();        // двусторонняя связь, только явно
```
- Пропсы не мутировать; сообщать наверх колбэком или `$bindable`.
- Если у bindable есть значение по умолчанию, родителю при `bind:` надо передать не-`undefined`.
- Имя `children` зарезервировано под содержимое компонента.

## $inspect

Только dev; в production — пустая операция. `$inspect(a, b)` — как `console.log` при каждом изменении (глубоко), со стеком. `$inspect(x).with((type, v) => ...)` — свой обработчик (`'init'`/`'update'`). `$inspect.trace()` (5.14+) — первым оператором функции: покажет, какое состояние перезапустило эффект/derived.

## $host

Только для custom elements; нам не нужен.

## await в разметке и $derived

Экспериментально (`compilerOptions.experimental.async`), требует `<svelte:boundary>` с `pending`. В проекте **не включено** и не используется.

## Классы и стили

`class={{ cool, lame: !cool }}` (объект и массивы, как clsx), `style:width="{size}px"`, `style:--x={v}`.
