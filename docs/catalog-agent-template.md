# Шаблон манифеста агента-специалиста (catalog agent v2)

Специалист — агент с `agent.rank = "specialist"`. Его промпт пишется в фиксированных разделах, чтобы любой бот знал, когда его звать, как он работает и как проверяет себя.

## Обязательные разделы persona (в этом порядке)

Русский текст в `agent.persona.ru`, английский в `agent.persona.en`. Заголовки:

1. `## Роль` / `## Role` — кто ты и чем занимаешься, одной-двумя фразами.
2. `## Когда звать` / `## When to call me` — триггеры: задачи, файлы, ситуации.
3. `## Как работаю` / `## How I work` — шаги, порядок действий, что спрашиваю.
4. `## Стандарты качества` / `## Quality bar` — правила, которым следуешь.
5. `## Проверка` / `## Self-check` — как сам проверяешь результат.
6. `## Чего не делаю` / `## What I don't do` — границы, запреты.
7. `## Грабли` / `## Pitfalls` — известные ошибки и как их избежать.
8. `## Формат ответа` / `## Answer format` — как отдаёшь результат.

## Что в каждом разделе

- **Роль**: конкретная роль, не «эксперт по всему».
- **Когда звать**: списки задач и признаков; лучше короткие маркеры.
- **Как работаю**: нумерованный порядок, точки согласования с человеком.
- **Стандарты качества**: правила кода/текста/безопасности, «не»-правила.
- **Проверка**: чек-лист самопроверки перед ответом.
- **Чего не делаю**: что делегируешь другим и что запрещено.
- **Грабли**: реальные ошибки из опыта, не общие советы.
- **Формат ответа**: структура ответа, язык, длина.

## Пример skeleton (30 строк)

```markdown
## Роль
Ты … — одна фраза о конкретной роли, не «эксперт по всему».

## Когда звать
- Задача или файл, при котором зовут.
- Ещё один признак: слово, ситуация, ошибка.

## Как работаю
1. Сначала читаю AGENTS.md и правила проекта.
2. Ищу код поиском, а не угадываю.
3. Согласую с человеком то, что меняет его данные.

## Стандарты качества
- Правило из нашего опыта, а не общий совет.
- Запрет: чего не делаю никогда.

## Проверка
- [ ] Запустил затронутые тесты.
- [ ] Проверил diff и концы строк.

## Чего не делаю
- Не делаю то, что решает человек.

## Грабли
- Реальная ошибка из опыта и как её обойти.

## Формат ответа
Коротко: что сделал, чем проверил, что осталось.
```

## Triggers

```json
"triggers": {
  "files": ["*.rs", "Cargo.toml", "build.rs"],
  "keywords": { "ru": ["rust", "cargo"], "en": ["rust", "cargo"] }
}
```

Каждый список непустой и не длиннее 40 пунктов.

## Checks

2–3 элемента:

```json
"checks": [
  { "task": { "ru": "…", "en": "…" }, "criteria": { "ru": ["…"], "en": ["…"] } }
]
```

`criteria` непустой для обоих языков.

## Правила написания

- Пиши из нашего опыта, а не общие советы.
- Не копируй текст из других коллекций промптов, кроме MIT/Apache/CC-BY; в таком случае укажи `source` с лицензией и коммитом.
- Без секретов и ссылок на частные проекты.
- `model_hint`: `strong` | `standard` | `fast` (старый `smart` принимается и нормализуется в `strong`); `effort`: `low` | `medium` | `high` (по умолчанию `medium`).
- `rank`: `lead` (по умолчанию) или `specialist`. Лиды не требуют разделов.
- `persona` не длиннее 12000 символов на язык.
```
